# قرارداد API کاتالوگ

این سند قرارداد اولیه دسته‌بندی محصولات را ثبت می‌کند. این بخش هنوز به محصول، قیمت، موجودی یا نوع کالا وابسته نیست.

## دسته‌بندی‌ها

هر دسته‌بندی دارای نام، شناسه یکتای URL، توضیحات اختیاری، والد اختیاری، ترتیب نمایش و وضعیت فعال/غیرفعال است. ساختار درختی با `parent_id` نگهداری می‌شود؛ پاسخ فهرست به‌صورت مجموعه تخت است تا کلاینت بتواند درخت را بدون محدودیت عمق بسازد.

### مسیرهای عمومی

| متد | مسیر | توضیح |
|---|---|---|
| GET | `/api/v1/categories` | فهرست دسته‌بندی‌های فعال |
| GET | `/api/v1/categories/{slug}` | جزئیات دسته‌بندی فعال با slug |

دسته‌بندی غیرفعال در API عمومی نمایش داده نمی‌شود و درخواست جزئیات آن پاسخ 404 می‌گیرد.

### صفحه مدیریت

صفحه مدیریت دسته‌بندی‌ها در مسیر `/admin/categories` قرار دارد و فقط برای مدیر واردشده و تأییدشده قابل مشاهده است. این صفحه از API مدیریتی زیر برای عملیات داده استفاده می‌کند و در منوی کناری فقط به مدیران نمایش داده می‌شود.

### مسیرهای مدیریتی

تمام مسیرهای زیر به نشست احراز هویت‌شده Sanctum و مجوز `access-admin` نیاز دارند.

| متد | مسیر | توضیح |
|---|---|---|
| GET | `/api/v1/admin/categories` | فهرست صفحه‌بندی‌شده همه دسته‌بندی‌ها |
| POST | `/api/v1/admin/categories` | ایجاد دسته‌بندی |
| PATCH | `/api/v1/admin/categories/{id}` | ویرایش دسته‌بندی |
| DELETE | `/api/v1/admin/categories/{id}` | حذف دسته‌بندی بدون زیردسته |

### فیلدهای ورودی

- `name`: الزامی، رشته حداکثر 160 کاراکتر
- `slug`: الزامی هنگام ایجاد، یکتا و ASCII alpha-dash، حداکثر 180 کاراکتر
- `description`: اختیاری، حداکثر 10000 کاراکتر
- `parent_id`: اختیاری، شناسه دسته‌بندی والد موجود؛ چرخه و انتخاب خود دسته به‌عنوان والد مجاز نیست
- `sort_order`: اختیاری، عدد صحیح نامنفی
- `is_active`: اختیاری، مقدار boolean

### رفتار حذف

حذف دسته‌بندی دارای زیردسته با پاسخ 409 رد می‌شود. ابتدا باید زیردسته‌ها منتقل یا حذف شوند. در صورت حذف یک دسته‌بندی بدون زیردسته، رکورد حذف می‌شود.

### پاسخ و خطاها

پاسخ‌های منابع در کلید `data` قرار می‌گیرند. خطاهای اعتبارسنجی 422، عدم ورود 401، نداشتن مجوز 403، نبود دسته‌بندی عمومی 404 و حذف دسته‌بندی دارای فرزند 409 هستند.

## موارد خارج از محدوده فعلی

- اتصال دسته‌بندی به محصولات (تا زمان پیاده‌سازی مدل محصول)
- تصاویر دسته‌بندی و SEO
- ترجمه چندزبانه
- مرتب‌سازی درختی با drag-and-drop
- آرشیو نرم و بازیابی دسته‌بندی
