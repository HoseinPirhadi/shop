# تنظیمات فروشگاه

## مدل داده

تنظیمات پایه در جدول تک‌ردیفی `store_settings` با شناسه ثابت ۱ نگهداری می‌شوند:

- `store_name`: نام نمایشی فروشگاه، اختیاری و حداکثر ۱۶۰ کاراکتر
- `currency_code`: کد سه‌حرفی ارز، nullable و بدون مقدار پیش‌فرض

مهاجرت، ردیف تنظیمات را با هر دو مقدار خالی ایجاد می‌کند. هیچ ارز یا بازار هدفی از محیط اجرا یا موقعیت کاربر حدس زده نمی‌شود.

## API

### عمومی

| متد | مسیر                     | کاربرد                        |
| --- | ------------------------ | ----------------------------- |
| GET | `/api/v1/store-settings` | نام فروشگاه و وضعیت تعیین ارز |

پاسخ عمومی شامل `store_name`، `currency_code` و `currency_configured` است.

### مدیریتی

مسیرها به نشست Sanctum و مجوز `access-admin` نیاز دارند:

| متد   | مسیر                           | کاربرد             |
| ----- | ------------------------------ | ------------------ |
| GET   | `/api/v1/admin/settings/store` | دریافت تنظیمات     |
| PATCH | `/api/v1/admin/settings/store` | به‌روزرسانی تنظیمات |

فیلدهای قابل ویرایش:

- `store_name`: رشته یا null، حداکثر ۱۶۰ کاراکتر
- `currency_code`: رشته بزرگ‌نویسی‌شده سه‌حرفی مطابق قالب ISO 4217 یا null

اعتبارسنجی فعلی قالب سه‌حرفی بزرگ را کنترل می‌کند؛ مدیر باید کد معتبر را از فهرست رسمی ISO 4217 انتخاب کند.

**محدودیت اعتبارسنجی:** API فعلی قالب سه‌حرفی بزرگ را بررسی می‌کند و عضویت کد در فهرست رسمی ISO 4217 را به‌صورت خودکار استعلام نمی‌کند؛ بنابراین کد انتخابی باید از فهرست رسمی معتبر برداشته شود.

## رابط مدیریت

صفحه تنظیمات در مسیر `/admin/settings` قرار دارد و از منوی مدیریت قابل دسترسی است.

## وضعیت قیمت‌گذاری و خرید

ثبت ارز فقط تنظیمات پایه را تکمیل می‌کند. قیمت‌گذاری محصولات، محاسبه مبالغ، سفارش، پرداخت و checkout هنوز پیاده‌سازی نشده‌اند و صرفاً با ثبت کد ارز فعال نمی‌شوند. پیش از پیاده‌سازی آن‌ها، قواعد مالی و بازار هدف باید مشخص شوند.

## سیاست تغییر ارز

در نسخه فعلی هنوز سفارش یا تراکنش مالی وجود ندارد؛ بنابراین مدیر می‌تواند کد ارز تنظیمات را اصلاح کند. پس از اضافه‌شدن سفارش و پرداخت، تغییر ارز نباید یک ویرایش ساده تنظیمات باشد و باید با کنترل سوابق مالی، مهاجرت داده و ثبت تاریخچه انجام شود.
