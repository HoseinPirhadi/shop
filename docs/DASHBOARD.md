# داشبورد و رابط فارسی

## داشبورد

مسیر `/dashboard` برای کاربر واردشده در دسترس است. محتوای داشبورد بر اساس نقش کاربر تفکیک می‌شود:

- مشتری داشبورد حساب خود را می‌بیند و به آمار مدیریتی دسترسی ندارد.
- مدیر آمار واقعی کاتالوگ و انبار را از دیتابیس دریافت می‌کند.

### شاخص‌های مدیریتی

- تعداد کل محصولات
- تعداد محصولات فعال و قابل نمایش
- تعداد دسته‌بندی‌ها
- تعداد گونه‌های فعال
- تعداد گونه‌های دارای کنترل موجودی
- تعداد گونه‌های دارای موجودی بیش از ۵ واحد
- تعداد گونه‌های کم‌موجودی با موجودی ۱ تا ۵
- تعداد گونه‌های بدون موجودی

فهرست محصولات تازه و آخرین تغییرات موجودی نیز نمایش داده می‌شوند. هر تغییر موجودی به سابقه ثبت‌شده در جدول `inventory_movements` متصل است.

تا پیش از پیاده‌سازی سفارش و پرداخت، هیچ شاخص ساختگی برای فروش، درآمد، سفارش یا مشتریان خریدار نمایش داده نمی‌شود.

## زبان و راست‌چین

- locale پیش‌فرض Laravel برابر `fa` و fallback نیز فارسی است.
- سند HTML با `lang="fa"` و `dir="rtl"` رندر می‌شود.
- فونت Vazirmatn در build فرانت‌اند بارگذاری می‌شود.
- پیام‌های اعتبارسنجی، احراز هویت و بازیابی گذرواژه ترجمه فارسی دارند.
- پنل مدیریت، ویترین، صفحات احراز هویت و تنظیمات حساب از چیدمان راست‌چین استفاده می‌کنند.

## الهام طراحی

ساختار بصری داشبورد از الگوهای رایج داشبوردهای فروشگاهی مانند VexUI الهام گرفته شده است؛ کد، تصاویر یا دارایی‌های اختصاصی قالب کپی نشده‌اند.
